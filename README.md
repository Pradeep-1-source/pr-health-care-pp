# PR HEALTH CARE – Modern Healthcare Clinic Website

A premium, responsive healthcare clinic website built for **PR HEALTH CARE** using Next.js 14, TypeScript, and Tailwind CSS.

## 🩺 Features

- **Home Page**: Hero with clinic branding, "Your Health, Our Priority", General Health Checkup highlight, Why Choose Us, and fast contact options.
- **Our Services**: Confirmed clinical services including:
  - General Health Checkup (Signature Checkup)
  - General Consultation
  - Preventive Healthcare
  - Basic Health Assessment
- **Appointment Booking Desk**: Validated patient appointment request form with slot selection, transparency notices, and instant WhatsApp continuation with pre-filled details.
- **Contact & Directions**: Direct calling (`7305053083`), WhatsApp messaging (`7305053083`), clinic timings, and embedded Google Maps.
- **WhatsApp Integration**: Persistent floating WhatsApp button on all pages with reception desk quick actions.
- **Modern Gray UI Theme**: Contemporary medical slate-gray background with clean white cards, medical blue accents, and soft teal highlights.

## 🚀 Getting Started

First, install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Or build and run in production mode:

```bash
npm run build
npm start
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the clinic website.
